🏛️ 3-Layer Component Control Architecture

LAYER 1

Skeleton Shell Creation

Constructs the outer layout container nodes (<table>, <form>, <thead>, empty <tbody> slot). Does NOT construct data rows or fields.

LAYER 2

Event Listener Hooks

Registers event handlers on skeleton DOM nodes. Hooks search input keyup listeners for in-place table filtering and form submit prevention.

LAYER 3

User UI & Data Hydration

Transforms raw data records (prepareTableData), constructs row DOM nodes, and mounts/refreshes them into container slots in-place.
