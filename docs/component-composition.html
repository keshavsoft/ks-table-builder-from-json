13. Component Factory

Conceptually, a component factory coordinates the composition process. 

const createTable = ({
    columns,
    data,
    theme
}) => {

    const godSpec =
        getGodSpec();

    const pipeline =
        createTablePipeline({
            columns,
            data,
            theme
        });

    const finalSpec =
        runPipeline({
            inSpec: godSpec,
            inTasks: pipeline
        });

    return buildDom({
        inSpec: finalSpec
    });

};

The exact implementation can differ; the important point is the separation of responsibilities.

Component composition is the process of assembling one complete specification from independent sources.

The God JSON supplies the structural foundation. Columns describe how data maps into the structure. Runtime data supplies the records. Renderers describe how individual values become cell content. Theme specifications provide presentation information. Middleware transforms the specification in an intentional order.

The result is one final specification tree. The generic recursive DOM builder then materializes that tree into DOM.

This keeps the component-specific composition logic separate from the generic mechanism that turns a specification into browser elements.
